ジェノグラムをExcelで作る方法と、つまずくところ

新しいツールを増やさずに済むなら、それに越したことはありません。Excel でジェノグラムを作る手順を具体的に示したうえで、どこで行き詰まるのかも正直に書きます。

下準備：方眼にする

Excel でジェノグラムを描くとき、最初にやるべきはセルを正方形にすることです。これをやらないと、図形の位置がそろわず、後で必ず苦労します。

  1. 全体を選択（左上の三角をクリック）
  2. 列の境界をドラッグして幅を「2.00（19ピクセル）」程度に
  3. 行の高さも同じく19ピクセル程度に
  4. 表示 → 目盛線をオンのままにしておく

これで方眼紙の状態になります。図形を配置するときに Alt を押しながらドラッグすると、セルの角にぴたりと吸着するので、位置がそろいます。

人物記号を作る

男性（四角）と女性（丸）

  1. 挿入 → 図形 → 「正方形／長方形」または「楕円」
  2. Shift を押しながらドラッグすると、正方形・正円になる
  3. 図形の書式 → 図形の塗りつぶし → 「塗りつぶしなし」
  4. 図形の枠線 → 黒、太さ 1.5pt 程度

サイズはすべて同じにします。最初の1つを作ったら、Ctrl+D で複製して使い回すのが確実です。手で描き足すと必ず大きさがばらつきます。

本人（二重枠）

四角（または丸）を作り、それを複製して少し大きくし、両方を選択して「グループ化」します。中央揃え・上下中央揃えで位置を合わせてからグループ化すると、後で動かしてもずれません。

死亡（斜線）

記号の上に「線」を1本引いて、記号と線をグループ化します。図形の「×」を重ねる方法もありますが、線のほうが印刷したときにきれいです。

名前と年齢を入れる

図形を右クリック →「テキストの編集」で図形の中に年齢を入れられます。名前は図形の下にテキストボックスを置きます。テキストボックスは「塗りつぶしなし」「枠線なし」にしておきます。

関係線を引く

関係作り方
婚姻「線」を水平に引く。Shift を押しながらで水平が固定される
離婚婚姻線の上に短い斜線を2本重ねる
別居婚姻線の上に短い斜線を1本重ねる
同居・内縁線の書式 → 実線／点線 → 破線を選ぶ
親子婚姻線の中点から下へ垂直線 → 水平に伸ばす → 各子へ垂直に降ろす。「カギ線コネクタ」を使うと楽
同居範囲「正方形／長方形」を置き、塗りつぶしなし・枠線を破線にして、囲みたい範囲に重ねる

コネクタ（挿入 → 図形 → 線 → カギ線コネクタ）を使うと、図形を動かしたときに線がついてきます。ただの「線」だと置き去りになるので、コネクタを使うほうが後の修正が楽です。

印刷の設定

  1. ページレイアウト → 印刷の向き（横のほうが収まりやすい）
  2. ページレイアウト → 印刷範囲 → 印刷範囲の設定
  3. ページレイアウト → 拡大縮小印刷 → 「1ページに収める」
  4. 図形を右クリック → 図形の書式設定 → プロパティ → 「オブジェクトを印刷する」にチェック

最後の項目が抜けていると、画面に見えているのに印刷すると図形だけ出てこないという事故が起きます。これは Excel でよくある落とし穴です。

Excel でつまずくところ

ここまでの手順で作れます。ただ、実務で回し始めると次の壁に当たります。

人を1人足すと配置が総崩れになる

「次男がいることが後から分かった」というのは日常茶飯事です。Excel だと、間に1人入れるために周囲の図形をすべて手で動かすことになります。子が4人いる家族で1人追加すると、線の引き直しを含めて10分では終わりません。

記号のルールを自分で覚えておく必要がある

「離婚は斜線2本、別居は1本」を毎回思い出すことになります。しばらく作らない期間があると、必ずどちらかを忘れます。専用ツールなら一覧に「離婚」「別居」と名前で並んでいます。

サイズと太さがばらつく

複製して使っていても、うっかり端をドラッグして大きさが変わります。印刷すると、そろっていない図は素人くさく見えます。担当者会議の資料としては気になるところです。

ファイルが人によってばらばらになる

事業所内で共有すると、各自が自己流に改変していきます。半年後には「最新版がどれか分からない」状態になります。

Excel で十分な場合とそうでない場合

状況判断
作るのが年に数回Excel で十分。新しいツールを覚えるコストのほうが高い
家族構成が単純（夫婦と子1〜2人）Excel で十分
担当が20人以上いて毎月どれかを更新する専用ツールのほうが早い
エコマップも作りたいExcel だと線種の描き分けが煩雑。専用ツール向き
事業所で様式をそろえたい専用ツールのほうが崩れない

判断の目安を一つ挙げるなら、「1枚作るのに20分以上かかっていると感じたら」です。それが月に何枚もあるなら、道具を変えたほうが早く回収できます。

選び方の観点はジェノグラム作成ツールの選び方にまとめています。
