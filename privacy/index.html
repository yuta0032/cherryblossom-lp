プライバシーポリシー

CHERRY BLOSSOM（以下「当方」）は、ケアマネジャー向け業務支援ツールおよび本サイトの提供にあたり、利用者の情報を以下のとおり取り扱います。

1. 基本方針

当方は、個人情報の保護に関する法律その他の関係法令およびガイドラインを遵守し、取得した情報を適切に取り扱います。とりわけ、ケアマネジャーの業務で扱われる情報には配慮を要する内容が含まれるため、後述のとおり、当方のサーバーに保存しない設計を採用しています。

2. 利用者（患者・被保険者）の情報の取り扱い

本ツールに入力された利用者（患者・被保険者）の氏名、住所、要介護度、心身の状態、家族構成等の情報は、当方のサーバーに送信・保存されません。

これらの情報は、ご利用中のブラウザ内でのみ処理され、作成された書類（Excel・PDF等）は、お客様ご自身の端末またはお客様が指定した保存先に保存されます。当方がその内容を閲覧・取得することはありません。

ただし、事業所名・担当者名・連絡先など、書類作成の利便のために入力された事業所側の情報は、お客様の端末内（ブラウザのローカルストレージ）に保存される場合があります。これも当方のサーバーには送信されません。端末のブラウザデータを消去することで削除できます。

3. 当方が取得する情報

当方は、以下の情報を取得します。

  • ご契約・ログインに関する情報（メールアドレス、契約状態）
  • お問い合わせの際にお知らせいただく情報（お名前、メールアドレス、内容）
  • 本サイトの閲覧に伴い自動的に送信される情報（Cookie、IPアドレス、ブラウザの種類、閲覧ページ等）

4. 利用目的

  • 本サービスの提供、本人確認、利用資格の確認のため
  • ご契約の管理、料金の請求のため
  • お問い合わせへの回答のため
  • 本サービスおよび本サイトの改善、不正利用の防止のため
  • 本サイトにおける広告の配信のため

5. Cookieと広告配信について

本サイトでは、第三者配信の広告サービスを利用する場合があります。

Googleなどの第三者配信事業者は、Cookieを使用して、ユーザーが本サイトや他のウェブサイトに過去にアクセスした際の情報に基づいて広告を配信します。

ユーザーは、Googleの広告設定でパーソナライズ広告を無効にすることができます。また、aboutads.infoにアクセスすれば、第三者配信事業者のCookieを無効にできます。

ブラウザの設定により、Cookieの受け取りを拒否することも可能です。その場合、本サイトの一部機能がご利用いただけないことがあります。

なお、広告は本サイト（紹介ページ）にのみ掲載し、利用者の情報を入力するツール画面には掲載しません。

6. アクセス解析について

本サイトでは、サイトの利用状況を把握するためにアクセス解析ツールを利用する場合があります。これらはCookieを使用して情報を収集しますが、個人を特定するものではありません。収集された情報は、各サービス提供者のプライバシーポリシーに基づいて管理されます。

7. 決済情報について

ご利用料金の決済には、Stripe, Inc.が提供する決済サービスを利用しています。クレジットカード番号等の決済情報は、同社のシステムにおいて直接処理され、当方がクレジットカード番号を取得・保存することはありません。

8. Google APIから取得した情報の取り扱い

本サービスは、ログイン手段としてGoogleアカウントによる認証を利用しています。この際に取得する情報は、メールアドレスおよび氏名（アカウントに登録された表示名）に限られ、利用資格の確認の目的にのみ使用します。

本サービスがGoogle APIから受け取った情報の使用および他アプリへの転送は、Google API Services User Data Policy（限定的使用の要件を含む）に準拠します。当該情報を広告目的で使用すること、第三者に販売すること、および汎用的なAI／機械学習モデルの学習に使用することはありません。

9. 第三者提供

当方は、法令に基づく場合を除き、取得した個人情報を本人の同意なく第三者に提供しません。ただし、本サービスの提供に必要な範囲で、前述の決済事業者、認証基盤、ホスティング事業者に対して、必要な情報の取り扱いを委託する場合があります。

10. 安全管理

当方は、取得した情報の漏えい、滅失またはき損の防止のため、通信の暗号化（HTTPS）、アクセス制御その他の必要かつ適切な措置を講じます。

11. 開示・訂正・削除のご請求

ご本人からの求めにより、当方が保有する当該本人の個人情報の開示、訂正、利用停止または削除に応じます。下記のお問い合わせ先までご連絡ください。

12. 本ポリシーの変更

本ポリシーの内容は、法令の変更やサービス内容の変更に応じて、予告なく変更されることがあります。変更後の内容は、本ページに掲載した時点から効力を生じます。

13. お問い合わせ
